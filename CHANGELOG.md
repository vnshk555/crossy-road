# CHANGELOG

Короткий журнал работы над проектом.

## Практика / домашняя работа №1

**Что сделал:**

- Реализовал полноценный аналог **Crossy Road** на Phaser 4 + TypeScript + Vite.
- Разработал процедурную бесконечную генерацию 4 типов полос:
  - **Трава (Grass)**: безопасная зона с препятствиями (деревья, валуны) и коллекционными золотыми монетками.
  - **Дорога (Road)**: горизонтально движущиеся машины разных классов (спорткары, седаны, грузовики) со световыми лучами фар и разной скоростью.
  - **Река (River)**: плавающие бревна разной длины, на которых игрок дрейфует по течению; при прыжке мимо бревна — падение в воду и всплеск.
  - **Железная дорога (Rail)**: переезд с мигающим светофором, предупреждающим звуковым сигналом и проносящимся на огромной скорости экспрессом.
- Создал воксельного цыпленка с анимацией прыжка по дуге, сквош-энд-стретчем (`squash & stretch`), поворачивающегося в сторону движения.
- Внедрил механику орла (Eagle Hazard): при бездействии более 8 секунд сверху пикирует хищник и уносит цыпленка.
- Добавил процедурный синтезатор звуков на Web Audio API (прыжок, удар о дерево, сбор монет, всплеск воды, хруст машины, гудок поезда, крик орла, финал) без внешних файлов.
- Реализовал адаптивное управление: стрелки / WASD, клики мыши, свайпы и виртуальный экранный D-Pad.
- Создал интерфейс с подсчетом очков, лучшим рекордом (`localStorage`), монетами, кнопкой Mute и модальным окном Game Over с возможностью рестарта по пробелу.

**Что пришлось убрать или упростить:**

- Вместо тяжелых 3D-моделей использовал стилизованный воксельный 2.5D стиль на процедурной векторной графике Phaser (быстро грузится на любых ПК, не требует внешних текстур).

**Что оказалось сложнее, чем ожидалось:**

- Точная синхронизация координат игрока при дрейфе на бревне по реке, чтобы цыпленок не падал в воду, пока находится в границах движущегося бревна.

**Где использовал AI и для чего:**
