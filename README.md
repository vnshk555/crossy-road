# 🍕 CYBER COURIER: Hot Delivery (Кибер-курьер)

Оригинальная аркадная игра в стиле киберпанк для курса **«Проектирование и разработка игровых приложений»**.

Стек: **TypeScript + Phaser 4 + Vite + Web Audio API**.

📖 **[Дневник разработки и архитектурный анализ (DIARY.md)](./DIARY.md)**: разбор 5 ключевых точек игры, диаграмма потоков данных и навигация по графу `graphify`.

## 🎮 Концепт и ответы на вопросы Практики №1

1. **Кто или что игрок?**
   - Кибер-курьер в неоновом светоотражающем дождевике с терморюкзаком доставки пиццы за спиной.
2. **Что он делает большую часть времени?**
   - Быстро лавирует через плотный трафик автономных кибер-каров, перепрыгивает по парящим платформам энергоканалов и уворачивается от скоростного гиперлупа.
3. **Зачем?**
   - Чтобы доставить заказ **горячим** до дверей клиента, заработать чаевые ($), выполнить норму смены и установить рекорд дистанции.
4. **Что мешает?**
   - **Главный враг — остывание заказа**: сверху тикает шкала температуры пиццы (от 100°C до 0°C). Если стоять на месте — пицца остывает с огромной скоростью!
   - Несущиеся беспилотники и спорткары с неоновым светом фар.
   - Энергетические каналы (падение в бездну без платформы).
   - Скоростной монорельс гиперлупа с предупреждающей лазерной сигнализацией.
   - Кибер-терминалы и голографические столбы на тротуарах.
5. **Когда игра заканчивается?**
   - Столкновение с транспортом (ДТП).
   - Падение в шахту энергоканала.
   - **Температура заказа упала до 0°C** — клиент отменяет заказ из-за остывшей пиццы!

## 🔥 Ключевые уникальные механики

1. **Шкала температуры заказа (Pizza Heat)**:
   - Вверху экрана отображается термометр (`100°C ... 0°C`).
   - Каждый шаг вперед подогревает пиццу (+0.8°C от активности).
   - Подбор **Термо-паков 🔥** на тротуарах мгновенно дает `+20°C`.
2. **Контрольные точки доставки (Двери клиентов)**:
   - Каждые 25 метров трассы находится зеленая неоновая зона клиента 🎯.
   - При пересечении раздается интерком-звонок, заказ считается успешно доставленным!
   - Начисляется бонус +$100 чаевых, выдается новый горячий заказ (100°C).
3. **Крипто-чаевые (🪙)**:
   - Сбор бонусов на пути для накопления общего заработка курьера.
4. **Процедурный Synthwave саунд-дизайн**:
   - Web Audio API синтезирует неоновые бипы шагов, звонок интеркома, разряды энергоканала, сирену Фазы 2 и звуки паузы без внешних файлов.
5. **Игровое время и Фаза 2 (Час пик)**:
   - В HUD тикает таймер чистого игрового времени (пауза останавливает таймер).
   - Ровно через 60 игровых секунд активируется **Фаза 2**: всплывающий неоновый баннер-предупреждение, трафик ускоряется на +35%, а поезда гиперлупа появляются значительно чаще.

## 🕹️ Управление

- **W / Стрелка вверх**: Рывок вперед
- **S / Стрелка вниз**: Шаг назад
- **A / Стрелка влево**: Шаг влево
- **D / Стрелка вправо**: Шаг вправо
- **Пробел / Enter**: Взять новый заказ (рестарт при поражении)
- **P / Escape**: Пауза / снятие с паузы
- **Мышь / Тачпад / Смартфон**:
  - Свайп в любую сторону.
  - Одиночный клик в направлении движения.
  - Экранный неоновый D-Pad в правом нижнем углу.
- **Интерфейс**: Кнопка паузы ⏸ / ▶ и кнопка звука 🔊 / 🔇 вверху справа.

## 🚀 Запуск и сборка

```bash
# Установка зависимостей
npm install

# Локальный запуск
npm run dev

# Проверка типов
npm run typecheck

# Сборка для публикации
npm run build
```
Публичная версия находится в папке `dist/` и публикуется на GitHub Pages.
