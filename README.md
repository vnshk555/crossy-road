# Crossy Road (Кросси Роад) 3D-Isometric Arcade

Проект аркадной игры в стиле **Crossy Road** для курса **«Проектирование и разработка игровых приложений»**.

Стек: **TypeScript + Phaser 4 + Vite + Web Audio API**.

---

## 🎮 Описание игры

Игрок управляет отважным цыплёнком, который должен перейти как можно больше опасных зон (дорог, рек, железнодорожных путей) и собрать золотые монетки.

### Игровые механики:
1. **Травяные зоны (Grass)**:
   - Безопасные островки отдыха.
   - Содержат препятствия (деревья, валуны), преграждающие путь.
   - Спавнят золотые монетки (`+5 монет`), увеличивающие банк игрока.
2. **Автомобильные дороги (Road)**:
   - Разнообразный трафик: быстрые спорткары, городские седаны и длинные грузовики.
   - Машины оснащены фарами, освещающими трассу.
   - Попадание под колеса приводит к сплющиванию (Splat!) и завершению игры.
3. **Бурные реки (River)**:
   - Нельзя прыгать в открытую воду — цыпленок тонет.
   - Для переправы нужно прыгать по плавающим бревнам.
   - Находясь на бревне, персонаж дрейфует вместе с течением.
4. **Скоростная железная дорога (Rail)**:
   - За 1.5 секунды до поезда светофоры начинают тревожно мигать, и раздается звон.
   - Затем на огромной скорости проносится экспресс, сотрясая экран.
5. **Орёл-охотник (Inactivity Hazard)**:
   - Если стоять на месте или отступать назад более 8 секунд, с неба пикирует орёл и уносит персонажа.
6. **Рекорды и сохранения**:
   - Максимальный счет (High Score) и монеты сохраняются в `localStorage`.

## 🕹️ Управление

- **W / Стрелка вверх**: Прыжок вперед (+1 очко)
- **S / Стрелка вниз**: Прыжок назад
- **A / Стрелка влево**: Прыжок влево
- **D / Стрелка вправо**: Прыжок вправо
- **Пробел / Enter**: Быстрый перезапуск при поражении
- **Мышь / Тачпад / Сенсор**:
  - Свайп в любую сторону.
  - Одиночный клик в направлении движения.
  - Виртуальный D-Pad в правом нижнем углу.
- **Звук**: Кнопка 🔊 / 🔇 в правом верхнем углу для переключения звука.

## 🚀 Запуск и сборка

### 1. Установка зависимостей:
```bash
npm install
```

### 2. Запуск локального сервера разработки:
```bash
npm run dev
```
Откройте в браузере: `http://localhost:5173/`

### 3. Проверка типов:
```bash
npm run typecheck
```

### 4. Сборка для публикации (Production Build):
```bash
npm run build
```
Собранная игра будет помещена в папку `dist/`.

## 🏗️ Архитектура кода

- [`src/game/GameScene.ts`](file:///c:/Users/ivanu/OneDrive/Рабочий%20стол/game/src/game/GameScene.ts) — основная игровая сцена:
  - процедурная генерация полос (`generateLane`, `setupLaneVisuals`);
  - управление и перемещение персонажа (`tryMove`, `onLand`);
  - физика бревен и дрейфа по воде (`findLogUnderPlayer`);
  - обнаружение коллизий (`checkCollisions`, `handleSquish`, `handleDrown`);
  - налет орла (`triggerEagleAttack`);
  - адаптивный HUD и модальное окно Game Over.
- [`src/game/SoundEffects.ts`](file:///c:/Users/ivanu/OneDrive/Рабочий%20стол/game/src/game/SoundEffects.ts) — процедурный генератор звуковых волн Web Audio API (прыжки, удары, вода, машины, поезд, сирена, орёл).
- [`src/game/config.ts`](file:///c:/Users/ivanu/OneDrive/Рабочий%20стол/game/src/game/config.ts) — конфигурация холста Phaser и параметров масштабирования.
- [`src/style.css`](file:///c:/Users/ivanu/OneDrive/Рабочий%20стол/game/src/style.css) — стили страницы, обрамления холста и неоновые акценты.
